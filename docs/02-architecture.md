# 架构与数据

| 模块 | 职责 |
| --- | --- |
| `contracts` | 类型、命令、错误和业务常量 |
| `domain` | 番茄、头条和共享领域规则 |
| `application` | 作者操作、Agent 协作、候选采纳，产品线通过 `ProductLineModule` 接入 |
| `workflow` | 模型输入、作业阶段、用量与缓存 |
| `storage` | SQLite 事务、版本、事件、搜索和备份 |

| `client` | 书房、交办、编辑与 Diff，经宿主命令访问数据 |

## 版本与事务

SQLite 中的当前修订是工作稿的来源，定稿修订与候选分别记录。正文写入在事务内检查当前版本和锁定状态。异步模型作业冻结输入，回执落地时再次校验。若作者已编辑，自治批次暂停。事实提案归属生成所读的修订，审批时再次检查正文。

自治批次保存章节队列、当前章、批次要求和停点。进程中断后，运行中的批次恢复为可继续状态。逐章确认、手动暂停、质量红线有独立的续跑语义。大书导入先暂存上传分段，在所有分段到齐后以一个事务导入并记录回执，重复提交复用该回执。

## 读路径

工作台快照复用章序，读取近期运行、当前待审候选与待核对的用量记录。自治轮询只返回所选批次的详细步骤，其余批次只返回摘要。全文搜索由 SQLite FTS5 提供，兼顾中文两字查询。事件序号让客户端跳过无变动的状态响应。
