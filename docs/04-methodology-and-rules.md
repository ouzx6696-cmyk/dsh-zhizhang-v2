# 创作规则

## 番茄长篇

写作上下文按共享写作内核、全书设定、卷幕里程碑和本章动态材料组织。动态材料可以包含本章要求、指定上章尾段、滚动摘要、当前视角知情信息、到期伏笔和适用技法。作者可以在上下文预览里查看各部分的预算和装配结果。

章纲决定本章场景走向。技法卡提供触发条件、执行步骤和例句。诊断从黄金三章、常见套话、段落节律、重复、章末钩子和视角等角度定位文本，结果供作者和 Agent 复核。精修可限定到指定段落。

定稿前需要本章审阅通过，最多两次审稿打回。设定具备生效和失效锚点，知情点按角色记录。世界书记忆提案可增加、修订和结束设定，已锁定设定保持保护。

## 今日头条

今日头条覆盖资讯线和故事线，每条线支持短图文、长图文和微头条。标题上限 34 字，微头条不设标题。质检通过线为 84 分，自动回改最多两轮。验收、授权和交付绑定同一正文修订，交付文件按规则附加固定尾句。

受保护常量定义于 [protected-rules.ts](../src/contracts/protected-rules.ts)。状态转换由对应产品的领域逻辑校验。
