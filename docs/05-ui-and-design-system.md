# 工作台导航与交互

侧栏「织章」打开书房。目录切换作品、卷幕和章节，编辑区管理当前稿，正文下方展示候选差异。右侧「共创」选择上章版本、交办或启动自治，作业区显示进度、暂停原因和恢复操作。

- 「规划」维护章节目标与视角。「世界书」审批事实、伏笔和摘要。「技法」管理写作卡片。
- 保存冲突时保留本地编辑内容，并提示重新核对当前稿。Diff 支持逐段和整稿采纳，连续精修显示使用的候选底稿。
- 导入完成后显示变更统计，导出区分别提供整书资产包和定稿 TXT。
- 对话面板沿用当前 DsH 会话。交办指令填入输入框，经确认后发送。

前端为 TypeScript ES 模块。视图使用共享控件、主题变量和布局样式，文本通过 DOM 文本节点渲染。快捷操作和异步刷新应保留输入焦点，过期读取结果不应覆盖当前作品。
